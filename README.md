# A Random Website

My very first website, built as a way of getting back into coding. It's a personal page about me, made with plain HTML and CSS, and it marks the start of my web development journey.

## About

I'm Cloud Jharence Saulog, a 19-year-old Industrial Technology student (specializing in Electronics Technology) at Bulacan State University and an aspiring web developer. I'm teaching myself HTML, CSS, and JavaScript one step at a time, and this project is where I practice what I learn.

## Features

- Header with navigation links that jump to each section of the page
- Introduction section with a profile photo and "About Me" bio
- Random Stuff section with an audio player and a video player
- Hobbies, skills, and a short "About Me" list using unordered, ordered, and description lists
- Contact buttons for Facebook, Instagram, and email
- Certifications section linking to a public Credly badge
- Custom styling: rounded header and footer, a circular profile picture, a custom font, and a full-page background image

## Built With

- **HTML5** for structure and content
- **CSS3** for styling (flexbox, custom `@font-face`, background images)
- **Bebas Neue** font for section titles

## Getting Started

1. Clone or download this repository.
2. Make sure the `Keeps/` and `fonts/` folders sit next to the HTML file and `style.css`.
3. Open the HTML file in any web browser. No build step or installation is needed.

## What I Learned

- Structuring a page with semantic elements (`header`, `nav`, `main`, `section`, `footer`)
- Linking sections with anchor links and IDs
- Embedding audio and video
- Laying things out with flexbox
- Styling with classes, IDs, borders, shadows, and custom fonts
